# 2.6 Сложение, вычитание, умножение и деление

Пришло время познакомиться с арифметическими операциями языка С. Начнем с самых очевидных:

| Операция  | Обозначение                |
|-----------|----------------------------|
| Сложение  | <p align="center"> + </p>  |
| Вычитание | <p align="center"> - </p>  |
| Умножение | <p align="center"> * </p>  |
| Деление   | <p align="center"> / </p>  |

Все эти операции можно использовать как **бинарные**, то есть слева и справа от них записываются выражения, над которыми выполняется соответствующая операция:

<p align="center"> <левый операнд> + <правый операнд> </p>
<p align="center"> <левый операнд> - <правый операнд> </p>
<p align="center"> <левый операнд> * <правый операнд> </p>
<p align="center"> <левый операнд> / <правый операнд> </p>

Здесь левые и правые операнды могут быть любыми выражениями, над которыми можно выполнять соответствующую армфметическую операцию. В самом простом случае - это переменные и числовые литералы.

**Все рассматривыемые операции являются именно операциями а не операторами. Это значит, они вычисляют значения и возвращают его.** Именно поэтому мы можем свободно присвоить вычисленный результат какой-либо переменной следующим образом:

```
int result = 10 + 5;
```

или так:

```
int result;
result = 10 - 5;
```

Здесь точка с запятой завершают этап превращения операции в завершенный оператор. Это означает что арифметические операции можно продолжать пока не встретится точка с запятой:

```
int result = 10 + 5 - 7 * 3;
```

Теперь обо всем по порядку. Посмотрим на работу операций сложения, вычитания и умножения непосредственно в программе:

```
#include <stdio.h>
 
int main(void)
{
    short a = -5;
    int b = 10;
    float c = 5.4f;
    double d = -6.5;
 
    int res_1 = a + b;
    short res_2 = 100 - b;
    float res_3 = 5.4 - c;
    double res_4 = d * 4;
 
    return 0;
}
```


Cначала объявляем переменные четырех разных типов с определенными значениями. Эти переменные в дальнейшем используются в арифметических операциях наряду с числовыми литералами. Язык С позволяет использовать смешанные типы данных в арифметических операциях. Чтобы разобраться как это работает, начнем с первой операции, сложения `a` и `b`. Они имеют разные типы данных `short` и `int`. По умолчанию компилятор языка С приводит все целочисленные значения к типу данных `int` (если этого типа не достаточно то приведение по возрастанию идет к `long` и далее к `long long`) и только потом выполняется операция сложения. Поэтому переменная `a` будет приведена к типу `int` и мы сможем получить сложение двух значений одного типа. Приведение к большему типу данных называется **операция повышением типа**.

В следующей строчке программы записана операция вычитания:

```
short res_2 = 100 - b;
```

Здесь все работает аналогичным образом. **Литерал** `100` по умолчанию представляется типом `int`, переменная `b` также имеет тип данных `int`, результат сохраняется в памяти как число типа `int`. Далее полученное значение типа `int` присваивается переменной `res_2` типа `short`. Перед присваиванием также происходит приведение типов, в данном случае значение `int` к типу `short` т.к компилятор самовольно поменять тип данных не может. Приведение к меньшему типу данных называется **операция понижение типа**, которая может привести к потере данных если присваиваемое значение не укладывается в тип `short`. На это всегда стоит обращать внимание при реализцаии арифметических операций. **Если встречается понижение типа данных, потенциально возможно потеря данных.

В следующей строчке:

```
float res_3 = 5.4 - c;
```

мы тоже видим понижение типа от `double` к `float`. Как мы помним, числовой литерал вещественного типа по умолчанию представляется как `double`. Переменная также приводится к этому типу и результат вычитания сохраняется на уровне типа `double`. После этого, значение `double` присваивается переменной `res_3` меньшего типа `float`. Снова имеем понижение типов и потенциальную возможность потери данных. Поэтому чаще всего на практике вещественные числа описываются типом `double`, чтобы избежать подобных преобразований. 

Наконец последня строчка:

```
double res_4 = d * 4;
```

Здесь вещественное число типа `double` умножается на целое число типа `int`. Cтрого говоря, компьютер не умеет выполнять арифметические операции с вещественными и целыми числами. В нем реализована арифметика либо над целыми, либо над вещественными, не смешивая их. Поэтому в данном случае число 4 будет приведено к типу `double`, и только потом выполнена операция умножения над **вещественными** числами.

Остается еще одна операция деления, теперь не составит труда понять принцип ее работы. Для этого запишем несколько вариаций:

```
#include <stdio.h>
 
int main(void)
{
    short a = -5;
    int b = 10;
    float c = 5.4f;
    double d = -6.5;
 
    int res_1 = 7 / 2;      /* 3 */
    double res_2 = -9 / 2;     /* -4 */
    float res_3 = a / c;    /* -0.9259... */
    double res_4 = d / b;   /* -0.65 */
 
    return 0;
}
```

Когда происходит деление двух целочисленных значений, то результат также получается **целочисленным**. В соответствии с стандартом `C99` дробная часть попросту отбрасывается без математических округлений числа. Именно так образуются целые значения. Это следует запомнить. Если же один из операндов является вещественным значением, то все числа приводятся к типу `double` и после этого выполняется операция деления. Поэтому переменные `res_3` и `res_4` принимают дробные значения.

### Операция приведения типов

Начинающие программисты при операции деления часто совершают ошибки, когда делят два целых числа и ожидают получить вещественное значение. В действительности происходит обычное целочисленное деление. Здесь может возникнуть вопрос: как разделить две целочисленные переменные чтобы получилось вещественное число? К примеру ситуация:

```
#include <stdio.h>
 
int main(void)
{
    short a = -5;
    int b = 10;
 
    double res_1 = a / b;      /* 0 */
 
    return 0;
}
```

Для этого необходимо привести обе переменные к типу `double` используя операцию приведения типов:

```
double res_1 = (double)a / (double)b;      /* -0.5 */
```

Перед переменной в круглых скобках указывается тип, к которому должны быть приведены данные. В этом примере значения переменныех `a` и `b` сначала приводят к типу `double`, затем выполняется операция деления над вещественными числами. В результате получаем вещественное значение: `-0.5`.

Если мы оперируем конкретными числовыми значениями:

```
double res_2 = 7 / 2;
```

то для получения вещественного значения удобнее всего записать их в виде вещественных чисел:

```
double res_2 = 7.0 / 2.0;
```

вместо того чтобы приводить целые числа к вещественному типу.

### Унарные операции - и + 

Операции - и + можно использовать не только как **бинарные** но и как **унарные**, то есть перед выражением ставить знаки минус и плюс следующим образом:

```
#include <stdio.h>
 
int main(void)
{
    short a = -5;       // -5
    int b = -a;         // 5
    int d = -(7 + a);   // -(7 + -5) = -2
 
    return 0;
}
```

В первом случае знак минус стоит перед числовым литералом 5 и определяет его как отрицательное число, которое затем, присваивается переменной. В следующей строчке минус указан перед переменной и инвертирует знак числового значения, которое присваивается переменной `b`. При этом значение в переменной а не меняется. В третьей строчке унарный минус поставлен перед выражением (7 + а). Соответственно, сначала вычисляется операция внутри скобок, затем выполняется инвертирование знака.

### Приоритеты арифметических операций

**Приоритет любой унарной операции в языке С выше, чем бинарной.** К примеру:

```
int res = -10 + 7;
```

сначала будет выполнен унарный минус и только после этого бинарная операция сложения. Или вот так:

```
int res = -10 * 7;
```

здесь также унарный минус будет присвоен к числу 10 и только после этого выполнится бинарная операция умножения.

Если рассматривать бинарные арифметические операции, то сначала выполняется умножение и деление, а затем сложение и вычитание. То есть, приоритет операций умножения и деления выше, чем у сложения и вычитания. Все ровно так как учат в школе на уроках математики. 
Например:

```
short a = -5, b = 7, c = 4;
double D = b * b - 4 * a * c;
```

Сначала умножение, затем бинарная операция вычитания. Стоит обратить внимание что порядок вычисления первого умножения `b * b` и второго `4 * a * c` c стандартом языка С не определен. Разработчики компиляторов могут делать это в произвольном порядке с целью повышения скорости работы программы. Поэтому нет гарантии что вычислится сначала `b * b` затем `4 * a * c`. **Порядок может быть другим**. А вот порядок вычисления подряд идущих арифметических операций с одинаковым приоритетом **всегда выполняется слева-направо**. То есть выражение `4 * a * c` cначала будет выполнено первое умножение, затем второе слева-направо. Поэтому запись вида:

```
double res = 5 / 3 * 2;
```

означает, что сначала делится `5` на `3` и результат умножается на `2`. Это эквивалентно выражению ` (5 / 3) * 2` иногда путаются и считают, что оно соответствует выражению `5 / (3 * 2)`. Но это не верно из-за строго порядка вычислений слева-направо.

Если нужно изменить порядок вычислений, то есть приоритеты, то для этого используются круглые скобки, например следующим образом:

```
int perimetr = 2 * (b + c);
```

Cначала будет вычислено выражение внутри скобок и только потом умножение на два.

Забегая немного вперед будет приведен пример программы, которая запрашивает два числа и на их основе вычисляет площадь треугольника:

```
#include <stdio.h>
 
int main(void)
{
    double height, a;
    
    printf("Enter the height and length of the triangle's base: ");
    int res = scanf("%lf %lf", &height, &a);
 
    if(res != 2) {      // проверка, что res не равна двум
        printf("Data entry error\n");
        return 0;       // завершение функции main и программы
    }
 
    double sq = height * a / 2.0;
    printf("The square of the triangle is: %.2f", sq);
 
    return 0;
}
```

Вначале с помощью `scanf()` осуществляется ввод высоты и основания треугольника, затем с помощью условного оператора `if` происходит проверка на корректность, а именно что данные были прочитаны корректно. Если переменная `res` не равна двум значит какое-то из значений не попала в переменную и выводится ошибка. Затем в случае прохождения проверки происходит вычисления в переменной `sq` типа `double` и печатается результат.
